# Filtered NCBI-nt

Filtered NT is generated using the nt file provided by NCBI. The initial filetering process
removes all unwanted taxonomy nodes and any of it's child taxonomy nodes. Further filtering
can then be done to get a subset of the filtered NT based on a provided list of taxonomy
nodes, using the taxonomic name for said nodes.


All desired taxonomy nodes (for inclusion or exclusion, depending on the mode) are 
identified in an input list generated by two steps:
1) Getting all taxonomy nodes which contain the strings in the user provided list; 
2) Getting all possible child taxonomy nodes of each child of the taxonomy nodess 
	from step 1. 

For example, "other sequences" (taxId: 28384) is excluded with all its child taxonomy 
nodes including "artificial sequence", "vector", "synthetic", and so on.
